# Curriculum map

| Audience | Goal | Core modules | Assessment |
|---|---|---|---|
| Customer administrator | Configure and operate the product independently | Foundations, configuration, user management, reporting, troubleshooting | Scenario-based knowledge check |
| Customer-success manager | Explain releases and guide adoption | Product value, release changes, demo flow, common questions, escalation | Recorded walkthrough and quiz |
| Partner / implementer | Implement and support customer use cases | Architecture, integration, API workflows, configuration, validation | Practical implementation exercise |

## Content formats

- Task-based documentation
- Short e-learning modules
- Annotated walkthrough videos
- Instructor-led or virtual sessions
- Quick-reference guides
- Release briefs
- Assessments and certification

## Governance

Each module has a product owner, technical reviewer, content owner, review date, and release dependency.
