MkDocs Configuration

A minimal, strict MkDocs setup — the build fails on unresolved navigation entries or broken cross-references rather than publishing a site with silent gaps.

mkdocs.yml

site_name: PulseOps Documentation
site_description: Docs-as-code portfolio sample
strict: true
nav:
  - Home: index.md
  - Writing standard: writing-standard.md
theme:
  name: mkdocs
markdown_extensions:
  - admonition
  - tables

Source pages

  • docs/index.md — describes the quality gates the pipeline enforces.
  • docs/writing-standard.md — the house style rules technical and editorial reviewers check against.
